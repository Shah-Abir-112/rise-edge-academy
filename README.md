# Rise Edge Academy

Git-first academy management platform.

## Portals
- Admin: admissions, students, teachers, classes, attendance, fees, salaries, notices, messages, reports, settings, activity log.
- Teacher: profile, classes, students, attendance, assignments, notes, messages, payments, schedule.
- Student: profile, classes, attendance, results, assignments, notes, fees, notices, messages, teachers.

## Run
Use any static server (GitHub Pages, Firebase Hosting, VS Code Live Server, etc.).

## Firebase
Firebase configuration is intentionally separated under `js/firebase/`. Replace the placeholders in `config.js` before enabling real authentication/database operations.
